## 🔍 How .gitignore Works

**File: `.gitignore`**
```
.env              ← Hide files named .env
node_modules/     ← Hide entire node_modules folder
*.log             ← Hide all .log files
build/            ← Hide build folder
```

**When you run `git push`:**
1. Git reads `.gitignore`
2. Ignores files matching the patterns
3. Only uploads files NOT in `.gitignore`
4. Protected files stay on your computer ✓

## 🔐 Security Checklist

Before pushing to GitHub, verify:

- [ ] `.env` file exists locally but will NOT upload
- [ ] `.env.example` has NO actual secrets (just keys like `GEMINI_API_KEY=your_key_here`)
- [ ] `.gitignore` contains `.env`
- [ ] `.gitignore` contains `node_modules/`
- [ ] Run `git status` - should NOT show .env or node_modules
- [ ] After push, check GitHub repo - confirm no .env file there
